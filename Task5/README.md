## Настройка сетевых политик

### Запуск кластера

Кластер должен быть запущен с CNI, запрещающим трафик вне явно заданных сетевых политик, например, Calico:

```bash
minikube start --cni=calico
```

### Создание сервисов

```bash
./create_apps.sh
```

### Сетевые политики

Определены в файле `non-admin-api-allow.yaml`.

Для применения к кластеру:

```bash
kubectl apply -f non-admin-api-allow.yaml
```

### Тестирование трафика

Для тестирования трафика между подами требуется запустить скрипт:

```bash
./test-traffic.sh
```
