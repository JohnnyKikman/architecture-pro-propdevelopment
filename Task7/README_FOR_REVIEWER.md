# Инструкция по запуску и проверке

## Запуск кластера с небезопасными подами

Выполняется через [validate-security.sh](verify/validate-security.sh). В логи выводятся возможные ошибки об отказе в создании пода.

## Запуск кластера с безопасными подами

Выполняется через [verify-admission.sh](verify/verify-admission.sh). В нем устанавливается и настраивается Gatekeeper, после чего создаются поды с "безопасными" манифестами. В логи выводятся сообщения об успешном создании всех констрейнтов и следом за ними подов.
