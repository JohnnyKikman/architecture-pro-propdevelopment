# Требования к безопасности

| Код | Требования                                                                                                                                                                      |
|-----|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| S1  | Все передаваемые данные должны быть зашифрованы (TLS 1.3)                                                                                                                       |
| S2  | Все хранимые в БД данные должны быть зашифрованы (AES-256)                                                                                                                      |
| S3  | Данные должны храниться и обрабатываться в соответствии с требованиями законодательства (152-ФЗ)                                                                                |
| S4  | Биометрические данные должны быть обезличены и токенизированы                                                                                                                   |
| S5  | Должен быть обеспечен аудит и логирование всех системных событий, а также генерироваться сообщения о подозрительных событиях (например, черезмерном количестве попыток доступа) |
| S6  | Должна быть реализована 2FA при первом входе собственника с нового мобильного или иного устройства                                                                              |
| S7  | Требуется реализовать ABAC для разграничения доступа к устройствам только для имеющих к ним отношение жильцов                                                                   |
| S8  | Должна быть внедрена ротация токенов, используемых для взаимодействия с системой умного дома                                                                                    |

# Протоколы доступа

## Аутентификация

* Аутентификация с нового устройства обязательно должна быть двухфакторной, с использованием OTP либо приложение-аутентификатора
* В качестве протокола предлагается выбрать OAuth 2.0 для безопасной передачи доступа к ресурсам
* Выдаваемые токены должны иметь короткий срок жизни и должен быть внедрен механизм их обновления

## Авторизация

* Требуется внедрить атрибутивное управление доступом (ABAC) для определения доступа пользователя к устройствам "умного" дома
* Внедрить дополнительные проверки доступа, если пользователь делает запрос из нестандартной локации
* Для сотрудников поддержки ввести механизм выдачи краткосрочных привелегий (JIT) на время, нужное для оказание поддержки

# Взаимодействие между системами

1. Пользователь делает запрос через систему компании

1. Пользователь делает запрос через мобильное приложение
2. При отсутствии токена, выполняется процедура обновления (refresh) токена
3. Производится проверка атрибутов пользователя для того, чтобы понять, имеет ли пользователь доступ к этому устройству (данные получаются из tenant-smarthome-db)
4. При совпадении атрибутов, сервис компании делает запрос со своим токеном к сервису партнера
5. Сервис партнера отдает данные с устройства либо поток видео с домофона пользователю
